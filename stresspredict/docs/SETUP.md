# One-time setup

You only do this once. If you get stuck, message the team lead.

## 1. Install three free tools

| Tool | What it does | Link |
|------|--------------|------|
| **Node.js** (choose "LTS") | Runs the app on your computer | https://nodejs.org |
| **VS Code** | Where you edit files | https://code.visualstudio.com |
| **GitHub Desktop** | Saves and shares your work (no commands needed) | https://desktop.github.com |

## 2. Make a GitHub account

Go to https://github.com and sign up. Send your username to the team lead so you can be added to the project.

## 3. Get the project

1. Open **GitHub Desktop** and sign in.
2. Click **File > Clone repository**.
3. Pick **StressPredict** from the list and click **Clone**.
4. Click **Open in Visual Studio Code**.

## 4. Start the app

In VS Code, open the terminal (**Terminal > New Terminal**) and type these two lines, pressing Enter after each:

```
npm install
npm run dev
```

The first one takes a minute. When you see a link like `http://localhost:5173`, hold Ctrl (Cmd on Mac) and click it. The app opens in your browser.

Leave the terminal running while you work. Your changes show up in the browser as soon as you save a file.

To stop the app, click in the terminal and press **Ctrl + C**.

## Next time

You only need to open the project in VS Code and run `npm run dev`.
